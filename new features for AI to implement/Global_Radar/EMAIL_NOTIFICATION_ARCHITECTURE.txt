   SECURITY ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

   Layer 1: Network Isolation
   • All services on internal Docker network (caddy_default)
   • No direct external access to backend services
   • Cloudflare Tunnel for secure external access

   Layer 2: Authentication
   • Gmail OAuth2 tokens (encrypted in n8n database)
   • NocoDB API tokens (environment variables)
   • Webhook endpoint (no auth required - internal only)

   Layer 3: Data Protection
   • TLS encryption (Cloudflare → Caddy → Services)
   • Public health data only (non-sensitive)
   • No PII or credentials in emails

   Layer 4: Monitoring
   • n8n execution logs (success/failure tracking)
   • NocoDB webhook logs (request/response history)
   • Health agents logs (processing metrics)
