🤔 WHY IS BODY READ-ONLY?

  NocoDB v3 = Automatic payload generation
  
  Old way (wrong): Manual payload editing with {{ json event }}
  New way (right): Auto-generated from table schema ✅
  
  Your findings table has these fields:
  • Id, date, agency, headline, summary, url
  
  NocoDB automatically includes ALL of them in the webhook payload.
  
  The n8n workflow is already programmed to receive this format.
  
  No customization needed!

🔍 WHAT NOCODB SENDS (AUTOMATICALLY):

  When you save a new finding, NocoDB sends:
  
  {
    "type": "records.after.insert",
    "data": {
      "table_id": "m0s3bmpa8qzp4eh",
      "table_name": "findings",
      "rows": [
        {
          "Id": 123,
          "date": "2026-01-31",
          "agency": "WHO",
          "headline": "Outbreak detected",
          "summary": "Details here...",
          "url": "https://who.int/article"
        }
      ]
    }
  }
  
  ↓
  
  n8n receives it
  
  ↓
  
  Generates HTML email
  
  ↓
  
  Sends via Gmail ✉️
